# DevOps-SATC
Repositório para devops

Em resumo, o DevOps é uma filosofia cultural, enquanto o SRE é uma implementação técnica dessa cultura focada em confiabilidade.

O que é DevOps?
O DevOps é uma cultura que promove a colaboração entre as equipes de desenvolvimento e operações para acelerar a entrega de software com qualidade. Ele busca eliminar silos (divisões) entre times, permitindo que o código chegue ao usuário final de forma rápida e segura.

O que é SRE?
Criado pelo Google, o SRE aplica princípios de engenharia de software para resolver problemas de operações. O objetivo central é garantir que os sistemas sejam escaláveis e altamente disponíveis.
